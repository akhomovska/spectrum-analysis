# Аналіз ефективності частотного спектру

Курсова робота з аналізу використання частотного спектру.

## Опис

Програма мовою Python для аналізу ефективності використання частотного спектру телекомунікаційних систем.

## Функції

- Генерація тестових сигналів
- Обчислення FFT (швидке перетворення Фур'є)
- Розрахунок метрик ефективності
- Побудова графіків
- Експорт в TXT/CSV
